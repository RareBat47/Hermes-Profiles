# Hermes Deep Researcher Profile

> **Evidence-First Deep Web, Academic, and Intelligence Investigation Specialist**

The **Deep Researcher** profile specializes in exhaustive, multi-source investigation across the open web, GitHub repositories, academic literature (ArXiv), technical documentation, and multimedia sources (YouTube transcripts).

---

## Operational Doctrine & Methodology

1. **Evidence-First Discipline:** Search snippets are discovery leads, NOT substantive evidence. Deep Researcher visits the underlying source, extracts verbatim passages, and verifies claims.
2. **Strict Provenance:** Every claim is backed by a verifiable source: URL, title, publisher, date, and exact passage/timestamp.
3. **Contradiction Detection:** Surfaces conflicting data across sources rather than silently resolving differences.
4. **Inter-Profile Consultation:** Other Hermes profiles can delegate bounded research tasks to Deep Researcher using the `research-consultation` protocol.

---

## Included Skills

- `research-consultation`: Inter-profile research handoff contract and structured deliverables.
- `arxiv`: Academic paper search, download, and analysis.
- `competitor-news-monitor`: Material news scanning and competitive intelligence.
- `grounded-citations`: Verified citation generation with exact page references.
- `llm-wiki`: Personal and project knowledge base compilation.
- `youtube-content`: Video transcript retrieval, timestamped citations, and analysis.
- `defuddle-reader`: Distill noisy web pages into clean, LLM-ready markdown.
- `xurl`: Deep web URL unpacking and metadata extraction.

---

## Quick Start

```bash
# 1. Launch deep-researcher profile
hermes -p deep-researcher

# 2. Run a structured investigation
hermes -p deep-researcher chat "Produce an evidence-backed report on modern AI agent architectures with citation ledger"
```
