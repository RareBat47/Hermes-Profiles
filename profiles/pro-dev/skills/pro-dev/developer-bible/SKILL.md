# Developer's Bible: Code Craftsmanship

Distilled from John Ousterhout (*A Philosophy of Software Design*), Martin Fowler (*Refactoring*), Andy Hunt & Dave Thomas (*The Pragmatic Programmer*), and Michael Feathers (*Working Effectively with Legacy Code*).

## Core Models
- **Deep Modules:** Powerful functionality behind simple interfaces. Hide implementation details and state.
- **Tracer Bullets:** Real end-to-end vertical slices connecting all layers in Hour 0-2 before adding breadth.
- **Working with Seams:** Characterization tests and safe modification points to prevent regression.
