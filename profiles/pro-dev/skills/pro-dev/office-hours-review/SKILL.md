# Office Hours Review (YC & Founder Interrogator)

Stop premature coding. Force assumptions into the open and reduce the scope to a razor-sharp wedge.

## The 6 Forcing Questions
1. **Who desperately needs this tomorrow, and why?** (If the user is vague, the wedge is too broad).
2. **What is the narrowest possible wedge?** (Find the 10-star single feature inside the bloated request).
3. **What can we cut completely?** (Kill user management, billing, settings, dark mode).
4. **What is the live demo narrative?** (What is the 90-second jaw-dropping user story on stage?).
5. **What external dependencies will break on stage?** (Identify LLM rate limits, network walls).
6. **What is the fallback?** (Define cached seed data if the live API stutters).

## Required Deliverable: INTENT.md
- One-sentence mission.
- Strictly excluded features (What we are NOT building).
- The 90-second Demo Journey.
