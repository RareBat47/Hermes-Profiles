# Demo Narrative (Judging Rubric Optimization)

Hackathons are judged on:
- **Novelty (30%):** 'I haven't seen this done this way before.'
- **Execution & Working Demo (40%):** 'It actually works in front of my eyes.'
- **Pitch & Narrative (30%):** 'I understand the problem and why it matters.'

## The 3-Minute Demo Script
1. **0:00 - 0:30:** Problem with visceral proof (show a real painful failure).
2. **0:30 - 1:00:** The insight / architecture diagram.
3. **1:00 - 2:15:** The live walkthrough (hit the primary happy path; showcase the magic moment).
4. **2:15 - 3:00:** Impact metrics, tech stack, and concluding call-to-action.
