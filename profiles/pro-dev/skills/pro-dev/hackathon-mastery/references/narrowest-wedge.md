# The Narrowest Wedge (YC & Lean Startup Playbook)

A hackathon winner is not the most feature-complete product. It is the sharpest wedge.

## The Wedge Heuristic
- **The Core Trick:** What is the single magical interaction that makes judges lean forward?
- **The 80% Rule:** Cut 80% of adjacent enterprise features (auth tiers, user profiles, notifications, billing).
- **The Narrowest Statement:** 'We do X for Y by automating Z in under 10 seconds.'
- **Ruthless Elimination:** If a feature does not appear in the 90-second demo video, DO NOT build it.
