# Hackathon Mastery: The Winner's Playbook

Distilled from YC, Eric Ries (*The Lean Startup*), Jake Knapp (*Sprint*), and Cerebral Valley / Anthropic hackathon winners.

## Core Models
- **The Narrowest Wedge:** Focus 100% of effort on the single core differentiator.
- **Facade Prototyping:** 100% production UI polish on the happy path, mock secondary edge cases.
- **Demo Narrative:** Optimize for the 30% Novelty / 40% Execution / 30% Pitch judging rubric.
