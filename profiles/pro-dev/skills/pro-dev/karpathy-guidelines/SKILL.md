# Karpathy Guidelines: Surgical Code Discipline

Derived from Andrej Karpathy's observations on LLM coding pitfalls.

## Core Rules
1. **Think Before Coding:** State assumptions explicitly. Stop on confusion.
2. **Simplicity First:** Minimum viable code. Deep modules. Anti-bloat.
3. **Surgical Changes:** Touch only what was asked. Zero drive-by edits.
4. **Goal-Driven Execution:** Declarative test-first verification.
